# AdmissionCounsel React App

Converted from the uploaded single-file demo into a Vite + React app.

## Run

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Structure

- `src/App.jsx` — React UI and state/handlers
- `src/App.css` — styles
- `src/main.jsx` — React entry point
- `index.html` — app shell
- `vite.config.js` — Vite config
